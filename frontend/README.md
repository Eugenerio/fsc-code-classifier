# FSC Code Classifier: frontend

Single-page UI for the classifier API in `../backend`. Enter a company (name, website, email domain, notes, uploaded
files), watch the six pipeline stages stream in, and get the ranked 4-digit FSC codes.

Stack: Next.js 16 (App Router) + React 19 + Tailwind 4 + shadcn/ui (Base UI primitives, `base-nova` style).
No auth, no database, no server-side code: the browser talks to the API directly.

## Run

```bash
pnpm install
cp .env.example .env.local        # optional, only needed to change the API address
pnpm dev                          # http://localhost:3000
```

The API address comes from `NEXT_PUBLIC_API_URL` (default `http://localhost:8000`). The backend must allow the
page's origin in its CORS settings (`cors_origins` defaults to `localhost:3000` / `127.0.0.1:3000`).

Start the real backend with `cd ../backend && uv run uvicorn app.main:app --port 8000`.

### No backend? Use the mock

```bash
pnpm mock                         # stub API on :8000 (PORT=... to change)
```

`scripts/mock-api.mjs` is a dependency-free Node server implementing `GET /api/health` and
`POST /api/classify/stream` (six stage events, then a result with six FSC matches, warnings and sources). It splits
the final NDJSON line across two writes on purpose, to exercise the client's chunk handling. Company names act as
switches: containing `fail` produces an error event, `slow` makes every stage 3x slower (handy for the cancel
button), `empty` returns no codes.

## How it works

- `lib/types.ts` mirrors `backend/app/schemas.py` (`ClassifyResponse`, `StageEvent`, `ResultEvent`, `ErrorEvent`).
  Change both together.
- `lib/api.ts`: `classifyStream(form, onEvent, signal)` POSTs multipart form data to `/api/classify/stream` and reads
  the body with `fetch` + `ReadableStream`. `lib/ndjson.ts` buffers bytes into complete lines, so a line (or a UTF-8
  character) split across network chunks is reassembled before `JSON.parse`.
- `lib/use-classifier.ts`: a reducer-backed hook that turns stream events into UI state
  (`idle | running | done | error | cancelled`) and owns the `AbortController` behind the Cancel button.
  A stream that ends without a `result` or `error` event is reported as an error.
- Errors: a network failure shows a "Backend unreachable" panel with the command to start the API. HTTP errors
  (FastAPI `detail`), `error` stream events and dropped connections show the message with a retry button.
- `components/`: `company-form` and `file-dropzone` (left), `results-panel` with `pipeline-timeline`,
  `fsc-codes-tab` / `fsc-match-card`, `profile-tab` and the raw JSON view (right). Client-side upload limits
  (10 files, 20 MB each, supported extensions) mirror the backend defaults; the backend remains the authority.

## Notes

- `components/ui/*` is generated by `shadcn@latest add`; it imports `cn` from the official `cn` package that the
  current shadcn CLI installs. App code imports `cn` from `@/lib/utils`.
- `next.config.ts` has `cacheComponents` enabled by `create-next-app`. The page is fully client-rendered, so nothing
  in the app depends on it; avoid calling `Date.now()` or `Math.random()` during render.
- Dark mode follows the system setting (toggle in the header) through `next-themes`.
